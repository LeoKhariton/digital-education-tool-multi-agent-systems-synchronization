# Цифровой образовательный ресурс, посвященный теме синхронизации мультиагентных систем

Демо-версия доступна по [сслыке](https://leokhariton.github.io/digital-education-tool-multi-agent-systems-synchronization/).

## Постановка задачи
Требовалось разработать электронный образовательный ресурс (ЭОР, цифровой образовательный ресурс – ЦОР), посвящённый теме «Синхронизация мультиагентных систем», имеющий современный пользовательский интерфейс и включающий теоретический материал и краткие конспекты в виде презентаций, а также тесты самопроверки по каждому разделу.

## Актуальность темы
Современное развитие информационных технологий и широкое внедрение мультиагентных систем в различных областях (робототехнике, распределённых системах) делают проблему изучения управления мультиагентными системами чрезвычайно актуальной.

Разработка электронных обучающих ресурсов позволяет повысить доступность и качество образования в этой области, предоставляя пользователям интерактивные инструменты для изучения сложных теоретических концепций и практических навыков.

Электронные учебные пособия обеспечивают индивидуальный темп обучения, включают мультимедийные компоненты и позволяют быстро адаптироваться к изменяющимся образовательным потребностям и техническим требованиям.
Таким образом, разработка современного электронного образовательного ресурса по теме «Синхронизация мультиагентных систем» является актуальной.
Разработанный ЦОР может быть использован в Арзамасском политехническом институте при проведении лекционных и практических занятий в рамках подготовки магистров по направлению 01.04.04 «Прикладная математика» по дисциплине «Современная теория управления», а также для самостоятельной работы.

## Обоснование выбранных методов и средств разработки
Для создания данного электронного образовательного ресурса были применены веб-технологии, что обеспечило следующие ключевые преимущества:

- кроссплатформенность и универсальность (веб-приложения не зависят от конкретной операционной системы – для их запуска подойдет любой современный браузер);
- интерактивность (интеграция динамических элементов: тестов, симуляций, анимаций, что улучшает восприятие сложных теоретических концепций);
- удобство использования (установка и обновление не требуются);
- богатый графический интерфейс;
- доступность (ресурс может быть размещён на облачных платформах и легко масштабироваться для большого числа пользователей);
- простота разработки и обслуживания (веб-формат упрощает добавление нового контента, исправление ошибок и адаптацию под изменяющиеся образовательные стандарты или технические требования);
- возможность масштабирования и интеграции с другими системами.

Рассмотрим средства разработки более подробно.

**HTML5** (англ. Hyper Text Markup Language – язык разметки гипертекста) – это стандартный язык для форматирования веб-страниц. Он используется для создания их структуры и определения содержимого – текста, изображений, контейнеров и других элементов с помощью тегов.

**CSS3** (англ. Cascading Style Sheets – каскадные таблицы стилей) – это язык для описания внешнего вида документа. Он позволяет задавать цвета, шрифты, размеры и расположение элементов на странице. Основное преимущество CSS – возможность изменять внешний вид элементов отдельно от их содержания, что делает код более универсальным и масштабируемым.

**JavaScript** (JS) – это язык программирования, который используется для создания интерактивных элементов на веб-страницах. Он позволяет добавлять функциональность к странице и обеспечивать динамический контент. Также несомненным плюсом JS является то, что это – интерпретируемый («скриптовый») язык. Код работает непосредственно в браузере, не предварительной компиляции.

Для отображения математических формул в электронных документах и на веб-страницах чаще всего используется синтаксис **$`\LaTeX`$**. $`\LaTeX`$ – это система подготовки и вёрстки документов, а также язык разметки, базирующийся на макрорасширениях системы $`\TeX`$. Основная цель $`\LaTeX`$ – упростить набор сложных технических и научных текстов, включающих формулы и ссылки. Благодаря своей гибкости и мощным возможностям верстки, $`\LaTeX`$ стал очень популярным инструментом среди математиков, физиков, инженеров и других специалистов, которым необходимо точно оформлять технические документы. Для отображения $`\LaTeX`$-формул в веб-документах обычно используется библиотека `MathJax` или её альтернатива `KaTeX`.

Поскольку разрабатывается веб-приложение без серверной части с базой данных, удобно хранить контент, отображаемый на страницах приложения, в формате **JSON**. JSON (англ. JavaScript Object Notation) – это текстовый формат для хранения и передачи структурированных данных. Он основан на синтаксисе объекта в JavaScript, но широко используется и во многих других языках программирования.

Для быстрого создания презентаций применялась утилита **Marp**, которая использует лёгкий и интуитивно понятный язык разметки для форматирования текста Markdown. В отличие от HTML, где для форматирования применяются громоздкие и сложные теги, разметка **Markdown** встроена прямо в текст, что делает восприятие и редактирование более наглядным и удобным. Помимо прочего, Markdown содержит встроенные инструменты для визуализации подсветки синтаксиса программного кода, а также отображения формул в TeX-формате. Этот язык разметки на данный момент широко применяется для написания документации, заметок, блогов и презентаций. Использование Marp позволяет создавать слайды с визуальной структурой, при этом сохраняя прозрачность и простоту редактирования контента. Такой подход хорошо подходит для подготовки учебных материалов, где важна быстрая адаптация и поддержка наглядности. 

## Краткое описание контента

В ЭОР представлен комплексный материал, посвящённый теме «Синхронизация мультиагентных систем». Представлен подробный вывод необходимого и достаточного условия синхронизации, а также анализ условий синхронности для систем с линейной динамикой.

Для агентов с индивидуальной динамикой рассматривается принцип внутренней ссылки, который утверждает, что агенты должны обладать общей динамикой для того, чтобы синхронизация была возможна. Особое внимание уделено сетям нелинейных осцилляторов Курамото, которые демонстрируют ключевые явления синхронизации в нелинейных распределённых системах.

Учебный материал структурирован на следующие разделы:

1. Задача синхронизации. Приводится постановка и общая формулировка проблемы синхронизации мультиагентных систем.
2. Модели. Приведены модели агента, сетевого контроллера и сетевой системы в целом. Главная задача синхронизации автономных агентов решается с помощью сетевого контроллера, который управляет агентами и направляет их на общую траекторию поведения.
3. Условия асимптотической синхронизации. Представлены критерии, обеспечивающие устойчивое сходство поведения агентов с течением времени.
4. Синхронная траектория. Приведено описание общей траектории, к которой стремится система синхронизированных агентов.
5. Диффузионные связи. Рассмотрен анализ влияния диффузионных взаимодействий между агентами для успешной синхронизации.
6. Также рассматривается синхронизация в полносвязных сетях, где каждый агент напрямую взаимодействует со всеми остальными, что представляет собой особый случай с высокой степенью координации.

Данный образовательный ресурс предоставляет глубокое понимание основных принципов и методов синхронизации в мультиагентных системах, сочетая теоретический материал с наглядными примерами и тестами для самопроверки.

## Описание разработанного веб-ресурса

Для запуска разработанного веб-ресурса необходим любой современный веб-браузер с поддержкой HTML5, CSS3 и JavaScript.

Минимальные требования к версии браузера: IE 11 / Google Chrome 43 / Microsoft Edge 20 / Opera 12 / Yandex 15 / Safari 5 / Firefox 4. 
Тестирование приложения проводилось в браузерах Yandex 23, Google Chrome 110, Microsoft Edge 114 и Opera 95.

После запуска файла `index.html` загружается «главная» страница ЭОС.

Кнопка для перехода к тесту будет неактивна до тех пор, пока не будет заполнено поле с именем. Нажатие на кнопку «Закрыть» или любой клик вне модального окна вызовет его закрытие и вернёт пользователя на страницу с теорией. Авторизация служит также подтверждением намерения пользователя перейти к тестированию и защищает от случайных нажатий по вкладке.
